# 대학 공시 레이스

국내 대학의 연구활동과 학생지원 여건을 공시연도별로 비교하는 웹사이트입니다. 관심 있는 대학을 찾아 종합 순위와 학생지원 순위를 각각 살펴볼 수 있습니다.

**진학 참고용입니다.** 공개 자료에 이 프로젝트의 배점을 적용한 결과이며, 입시 합격선과 평판은 평가 항목에서 제외합니다. 지원할 학과의 전형과 입시 결과는 [대입정보포털 어디가](https://www.adiga.kr/)에서 확인하세요.

[대학 공시 레이스 열기](https://kor-uni-ranking.vercel.app)

## 관심 있는 대학 비교하기

1. **대학 찾아보기**에서 대학 이름을 입력하고 비교 기준을 고릅니다. 장학금이나 기숙사 같은 학생 생활 여건이 궁금하다면 **학생지원만**을 선택하세요.
2. **순위 레이스**에서 공시연도를 선택하거나 **연도 재생**을 눌러 연도별 순위 변화를 봅니다.
3. **전체 순위**에서 대학을 20곳씩 조회합니다. 화면 아래 **입시·공시 자료 찾아보기**에서 대학알리미, 어디가, 한국장학재단 등 원자료로 이동할 수 있습니다.

## 점수는 어떻게 계산하나요?

| 비교 기준 | 산정 방식 |
| --- | --- |
| 종합 순위 · 100점 | 연구활동 50점과 학생지원 50점을 더합니다. 연구활동은 공시연도 직전 3개년의 출판물 수와 인용 수에 각각 25점을 배정합니다. 학생지원은 아래 점수를 절반으로 환산합니다. |
| 학생지원 순위 · 100점 | 등록금 20점, 장학금 18점, 기숙사 수용률 12점, 취업률 12점, 교원당 학생 수 10점, 교육비 8점, 전임교원 강의 비율 8점, 도서 자료 6점, 글로컬대학 지정 6점입니다. |

글로컬대학 지정 점수는 사업 참여 기회를 반영합니다. 개별 학생이 받은 지원 금액은 따로 집계하지 않습니다. 연구 지표는 대학 규모와 전공별 출판 관행의 영향을 받습니다. 같은 대학도 두 기준에서 순위가 달라질 수 있습니다.

학생지원 공시값은 [대학알리미](https://www.academyinfo.go.kr/main/main2130/doInit.do), 연구 지표는 [OpenAlex](https://openalex.org/)에서 가져옵니다. 화면의 **순위는 어떻게 계산했나요?**를 펼치면 항목별 산식과 산정 제외 기준을 볼 수 있습니다.
